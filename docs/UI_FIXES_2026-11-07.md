### 过程问题与修复

1. **弯引号破坏 Slint**：重写分组栏时字符串字面量被写成弯引号（U+201C/201D），编译
   解析失败——经 node UTF-8 安全替换为直引号（不经 PowerShell，遵守 GBK 代码页教训）。
2. **顶层组件取不到窗口属性**：`PillButton` 引用 `root.theme` 失败；全局 `<=>` 双向绑定
   语法在 Slint 1.18 不支持——改为全局 `UiContext` + Rust `apply_theme` 同步。
3. **Flickable 弃用 API**：`viewport-width/height` 已弃用，改 `content-width/height`。
4. **clippy 参数上限**：`hit_test_scrolled` 8 参数触发 `too_many_arguments`，重组为
   `ScrollOffsets` 结构而非 allow 抑制。
5. **滚动补偿语义纠错**：初版对负向超滚做 `.max(0.0)` 钳制，会 把超滚空白判回首 tab；
   修正为直接加偏移（x+offset<14 自然落空白），并写进定向测试。
