# 1.2.1 优化性能对照

测量日期：2026-11-08。基线：`7b7c3133b239c3c7115f6f63c9e6cf45ddbb8be7`（工程版本 1.2.0）。优化后：本轮 1.2.1 工作树。数据层生产实现测量后未改动，随后只修正两处测试的预期分数。

环境为 Windows 11 Professional x64，OS build 26200，Rust/Cargo 1.96.0，`x86_64-pc-windows-msvc`、Release。工具详细版本见同目录 `rustc-version.log` 和 `cargo-version.log`。基线源码由 `git archive 7b7c313` 隔离提取，使用同一份 `examples/performance.rs` 的副本编译，避免修改当前工作树或覆盖当前 example。

采用合成数据和独立临时目录，不读取真实配置，不调用桌面、网络或应用启动。各组采用中位数；文件系统缓存已预热。搜索“冷”表示进程内拼音索引未准备，并非冷磁盘。clone 15 次、serialize 7 次、record/save 与 prune 各 5 次、重复选择 3 次、行构建 3 次、冷搜索 3 次、热搜索 7 次。所有成对 case 的项目数量和 BLAKE3 数据指纹一致。

原始数据：[`before.json`](before.json)、[`after.json`](after.json)。逐 case 对比：[`comparison.json`](comparison.json)。这些文件的长度和 SHA-256 见 [`performance-evidence.json`](performance-evidence.json)。执行日志：[`performance-before.log`](performance-before.log)、[`performance-after.log`](performance-after.log)。

```powershell
cargo run --locked --offline --release --example performance -- --label after-1.2.1 --out target/performance-new.json
```

本结果只覆盖上述隔离工作负载，不代表真实 UI 端到端延迟，不保证其他硬件或机器上的耗时相同。最终图标队列、统计合并和键盘交互正确性以对应确定性回归及统一测试记录为准。
